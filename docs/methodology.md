# 方法学与检查表说明 · Methodology

本文件说明工作台内置检查表的方法学来源与使用边界。**条目均为依据公开规范拟定的自查断言（自拟表述），不是规范原文照抄；正式申报前必须与规范原文及主管部门最新要求逐条核对。**

## 1. CHEERS 2022（`CHEERS-2022`，28 项，风险：critical ×10）

Consolidated Health Economic Evaluation Reporting Standards 2022（ISPOR 经济评估指南良好实践任务组 II；Husereau D, et al. Value in Health 2022; 25(1):3-10；获 EQUATOR 网络收录、15+ 期刊共同背书，含中文译本）。

自查表按 28 项条目逐一拟定断言：标题与摘要、背景与目标、**健康经济分析计划（HEAP）**、目标人群、场景与地点、对照、时间范围、贴现率、结局的选择/测量/估值、资源与成本测量、币种与价格日期、模型原理与描述、分析与假设、异质性、分布效应、不确定性、患者参与、研究参数、主要结果（增量分析）、不确定性影响、参与影响、结论/局限/外推、资金来源、利益冲突、研究影响。

在线清单（官方下载链接见 ISPOR 官网 CHEERS 页面）；使用时建议逐项对照原文措辞。

## 2. 中国药物经济学评价指南（2020 版）（`CN-GUIDELINE-2020`，16 项）

中国药学会药物经济学专业委员会编（2020 年出版）。自查条目标注了指南十大板块：研究问题与设计（PICO）、研究视角、数据来源、成本（识别/计量/估价）、健康产出与效用测量、贴现、增量分析、敏感性分析（确定性/概率）、亚组与异质性、预算影响分析、报告与结论、质量控制与可溯源性、利益冲突与伦理、术语与参数规范。

## 3. 经济模型透明度与验证（`ISPOR-SMDM-MODEL`，13 项）

依据 ISPOR-SMDM 建模良好实践任务组系列报告，特别是 **Model Transparency & Validation** 报告中以"七问"为核心的框架（Value in Health 2012; 15(6):843-50 等，后续任务组报告持续更新）。七问按工作台语言改写为可判定的断言：

1. 模型结构、假设与输入对决策者透明可理解
2. 全部输入输出可逐项描述（无不可见硬编码）
3. 结构假设显式且与临床/经济学常识一致
4. 数值实现验证无误（单元测试、极端值、交叉核对）
5. 模型预测与外部数据对照且差异有解释
6. 模型能力覆盖决策问题（对照 PICO）
7. 独立方能复现结果（代码/参数/种子/环境可获取）

另补充 5 条内部验证实践：单元测试、退化检验、PSA 分布合理性、情景压力测试、代码审查；以及版本管理（唯一版本标识、已发布版本不可变）。

## 4. 分析数据完整性（`ALCOA-ANALYSIS`，14 项）

ALCOA+ 原则（WHO TRS 1033 Annex 4、PIC/S PI 041、MHRA GxP 数据完整性指南 2018）应用到药物经济学分析数据：可归属、清晰、同步、原始、准确 + 完整、一致、持久、可获得；以及分析场景特有要求：脚本/模型版本控制、计算可复现、数据锁库、导出留痕、系统审计追踪。

## 使用边界（重要）

- 检查表是**报告/模型质量的自查工具**，不是合规判定结论；最终判定由具备资质的人员作出。
- 条目编号与原文条款的对应关系需使用者自行核对（与 LeebertyGXP 项目的同类声明一致，见其 docs 与 README"已知的、未完成核实的部分"）。
- 就绪度评分的权重（critical=25 等）为本项目自选，不是行业标准。
- 中国指南章节编号以实际出版文本为准；医保谈判测算还存在主管部门的内部技术要求，工作台不替代。

## 计算器的口径说明（`src/domain/analysis.js`）

- **CEA**：ICER = Δ成本/Δ效果；占优（更省更有效）与被占优（更贵更差）时**不计算** ICER（比值无决策意义）；INMB = Δ效果×WTP − Δ成本；四象限判定；支付意愿阈值提示性说明"1-3 倍人均 GDP 为国内定价讨论常见参考区间，具体以主管部门口径为准"。
- **BIA**：增量视角（替代现有治疗组合后的净变化），允许逐年市场份额、3-10 年范围。
- **QALY**：效用×年数按年贴现（首周期自 t=0 起算），贴现率 0-20%。

所有计算写入 `analysis_calculations` 表与审计追踪（action=`analysis_calculated`），报告值可回溯到输入快照。
